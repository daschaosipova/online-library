# Онлайн-библиотека

Учебный проект: генератор статического сайта онлайн-библиотеки. Скрипт собирает HTML-страницы каталога книг по данным из `meta_data.json` и раздаёт их локальным сервером. Страницы полностью самодостаточны — их можно открыть даже без интернета.

Опубликованная версия сайта: **https://daschaosipova.github.io/online-library/**

Данные для библиотеки (тексты книг, обложки, описания, жанры) взяты с сайта [tululu.org](https://tululu.org/). Это учебный проект, созданный в образовательных целях на онлайн-курсе для веб-разработчиков [dvmn.org](https://dvmn.org/).

## Структура проекта

```
pages/        сгенерированные страницы каталога (index1.html … index10.html)
static/       статика: стили, скрипты, фавикон
media/        содержимое библиотеки: media/books/ (тексты) и media/img/ (обложки)
template.html, redirect.html — шаблоны страниц
render_website.py              — скрипт сборки
```

## Как скачать библиотеку себе (без программирования)

Если вы не программист и просто хотите читать книги, делать ничего не нужно — библиотека уже собрана и лежит в репозитории.

1. Откройте репозиторий на GitHub и нажмите зелёную кнопку **Code**, затем выберите **Download ZIP**.
2. Распакуйте архив в любую папку.
3. Откройте файл `index.html` (двойным кликом) — сайт откроется в браузере. Можно открыть и страницу каталога напрямую: `pages/index1.html`.
4. Листайте страницы каталога, чтобы выбрать книгу, и нажмите **Читать** — текст книги откроется в новой вкладке.

Интернет при чтении не нужен: стили, обложки и сами книги хранятся в репозитории и открываются локально.

## Запуск для разработки

Для запуска нужен Python 3.10+.

1. Склонируйте репозиторий или скачайте архив, как описано выше.
2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # macOS / Linux:
   source venv/bin/activate

   pip install -r requirements.txt
   ```

3. Запустите скрипт:

   ```bash
   python render_website.py
   ```

Скрипт соберёт все страницы каталога в папке `pages/`, выведет в консоль `All pages rebuilt successfully` и запустит сервер. Сайт будет доступен по адресу http://127.0.0.1:5500 — адрес появится в консоли.

Пока сервер работает, он следит за изменениями в `template.html`, `redirect.html` и `meta_data.json` и автоматически пересобирает страницы.

### Настройка путей

По умолчанию скрипт читает данные из `meta_data.json` и собирает страницы каталога в папку `pages/`. При необходимости пути можно переопределить — без правки кода, через аргументы командной строки или переменные окружения:

| Что настраиваем | Аргумент CLI | Переменная окружения | По умолчанию |
|---|---|---|---|
| Файл с данными о книгах | `--meta-path` | `LIBRARY_META_PATH` | `meta_data.json` |
| Каталог собранных страниц | `--site-dir` | `LIBRARY_SITE_DIR` | `pages` |

Примеры:

```bash
# Собрать страницы из другого файла данных в другой каталог
python render_website.py --meta-path data/test.json --site-dir test-pages

# То же через переменные окружения
export LIBRARY_META_PATH=data/test.json
export LIBRARY_SITE_DIR=test-pages
python render_website.py
```

Приоритет: аргументы командной строки переопределяют переменные окружения, переменные окружения — значения по умолчанию. Аргументы и переменные можно комбинировать.

> `--site-dir` должен указывать каталог верхнего уровня (например, `pages`, `test-pages`): страницы ссылаются на соседние каталоги `static/` и `media/` через `../`.

## Откуда скрипт берёт данные

- Данные о книгах хранятся в файле `meta_data.json` — это список словарей, по одному на книгу:

  ```json
  {
    "title": "Название книги",
    "author": "Автор",
    "img_src": "media/img/1234-1234.jpg",
    "book_path": "media/books/1234-Название книги.txt",
    "genres": "Фантастика, Приключения."
  }
  ```

  Скрипт не трогает само содержимое `media/` — файлы уже лежат рядом со страницами, и сайт просто ссылается на них по относительным путям.

- Обложки лежат в каталоге `media/img/`, тексты книг — в каталоге `media/books/`. Имена файлов в `meta_data.json` соответствуют этим каталогам.

- Первоначально данные (список книг, обложки, тексты) были собраны парсером с сайта [tululu.org](https://tululu.org/).
